# Steering

## UI Information Density

- UIに文字情報はなるべく含めない。
- 画面上の常時表示テキストは、SFC〜PS1時代のRPG/DRPG/戦闘UIくらいの情報量に抑える。
- 判断に必要な情報は、短いラベル、数値、アイコン、色、位置、アニメーションで伝える。
- 長い説明、計算内訳、履歴、補足文は常時表示しない。必要な場合はログ、details、hover、別画面へ逃がす。
- 1画面で読ませる文章は最小限にする。プレイヤーが「読む」より先に「見る」で判断できる状態を優先する。
- Command、敵カード、Dashboard、Resultは、短い単語と数字を中心にする。文章で説明しないと成立しないUIは再設計候補とする。
- M.O.E. / NAVIの発話は1文までを基本にし、UIの不足を会話文で補わない。

目安:
- 常時表示: `HP`, `Action`, `Fuel`, `Armor`, `Signal`, `Ammo`, `Risk`, `Cost`, `Gain` などの短い語。
- 非常時のみ表示: `LOW`, `LOCKED`, `WEAK`, `DANGER`, `RETURN` などの警告語。
- 畳む情報: 説明文、戦術理由、計算詳細、長いログ、アンロック条件、会話補足。
