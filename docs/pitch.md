# Devil Drive: Midnight Terminal

## One-liner

東京の夜間道路迷宮を車で走り、Devilを探知・攻撃・交渉・契約する、ダッシュボード型コマンドRPG。

## Core Fantasy

首都高の夜道で悪魔に遭遇し、車載端末と武装で切り抜ける。

## Core Loop

Approach → Encounter → Command → Contract/Defeat/Escape → Reward → Return/Garage

## Unique Points

- 車載ダッシュボードUI
- Devilとの交渉と契約
- 車両武装コマンド
- NAVI Forecast
- 東京/日本の都市怪異

## idea

Devil Drive: Midnight Terminal は、午前0時に開く東京の道路迷宮「夜環」を舞台にした、車載ダッシュボード型コマンドRPG。

プレイヤーはサルベージドライバーとして、車載AI M.O.E.と共に夜環へ潜る。
DevilをNAVIで探知し、主砲・副砲・S-E・Ramで戦い、Terminal越しにAnalyze / Talk / Contractを行う。
倒すだけでなく、契約した存在を車載モジュールとして積むことができる。

ゲームの中核は、Approach → Encounter → Command → Contract/Defeat/Escape → Reward → Return/Garage。
東京の夜・首都高・都市怪談・妖怪・機械霊を混ぜたDevil rosterで、車両戦闘と悪魔交渉を融合させる。
